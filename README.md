# RxRx2 ICCE paper

Working title: **Reliability-Aware Phenotype Screening from Public Morphological Embeddings under Replicate Scarcity and Plate Shift**.

This repository contains only the LaTeX manuscript, final figures and compact result tables. Experiment code and detailed CSV outputs live in the private companion repository `xrx2-screening-code`.

## Overleaf workflow

1. Create the Overleaf project *from this GitHub repository* when possible.
2. Use Overleaf's GitHub menu to pull/push manually; it is not automatic.
3. Avoid editing the same LaTex lines independently on GitHub and Overleaf before synchronization.
4. Never add raw images, archives, embeddings or model checkpoints to this repository.

The current manuscript includes the completed 6/3/2-channel ablation. Six- and three-channel models are evaluated with two seeds; the two-channel configuration remains exploratory with one seed.
